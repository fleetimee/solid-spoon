# Fitur-Fitur Admin Sistem Reservasi Ruangan

## Manajemen Pengguna

- Mengelola akun pengguna sistem
- Melihat daftar semua pengguna
- Mengatur hak akses dan peran pengguna

## Manajemen Ruangan

- Menambahkan ruangan baru ke sistem
- Mengedit informasi dan fasilitas ruangan
- Menghapus ruangan dari sistem
- Mengelola ketersediaan ruangan
- Mengunggah dan mengelola galeri foto ruangan

## Manajemen Reservasi

- Melihat semua permintaan reservasi
- Menyetujui atau menolak permintaan reservasi
- Memantau status reservasi ruangan
- Mengelola jadwal penggunaan ruangan
- Mengirim notifikasi email otomatis kepada pengguna saat reservasi disetujui atau ditolak

## Dashboard dan Statistik

- Melihat tren reservasi ruangan
- Memantau tingkat penggunaan ruangan
- Menganalisis ruangan yang paling aktif digunakan
- Melihat grafik status reservasi

## Notifikasi

- Menerima pemberitahuan tentang permintaan reservasi baru
- Mengelola dan memantau notifikasi sistem
- Menandai notifikasi sebagai telah dibaca/belum dibaca
- Membersihkan riwayat notifikasi

## Pengaturan Sistem

- Mengatur batas waktu reservasi
- Mengelola pengaturan aplikasi
- Mengkonfigurasi parameter sistem
